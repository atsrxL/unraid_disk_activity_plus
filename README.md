# Unraid Disk Activity Plus

A fork of [DerekChan65535/unraid-disk-activity](https://github.com/DerekChan65535/unraid-disk-activity) focused on conservative HDD wake attribution, wake history, power state, and live open-file visibility for Unraid 7.3+.

## Install

Paste this URL into **Unraid → Plugins → Install Plugin**:

```text
https://raw.githubusercontent.com/atsrxL/unraid_disk_activity_plus/main/disk.activity.plg
```

This fork intentionally keeps the internal plugin name `disk.activity`, so install it **instead of** the original Disk Activity plugin, not alongside it.

## UI

Open **Settings → User Utilities → Disk Activity Plus**.

The single plugin entry contains two tabs:

- **Open Files / Settings** — wake-tracker settings, history retention and a live list of regular files currently open on monitored HDD/ZFS storage.
- **Wake History** — physical STANDBY → ACTIVE history, per-disk wake counts, confirmed wake-source shares and Reset Wake Statistics.

A native Dashboard tile named **Disk Activity Plus - Open Files** can be shown/hidden and moved with Unraid's Dashboard content manager.

## Attribution model

- **HIGH** — fanotify observed the PID accessing the monitored filesystem immediately before the first physical block-I/O change.
- **MEDIUM** — no HIGH event was available and exactly one process had a matching open descriptor at I/O onset.
- **UNKNOWN** — no safe userspace attribution, or multiple processes were plausible.

Only HIGH events are credited to named wake-source percentages. MEDIUM candidates remain visible in event history but are grouped as unknown in source statistics.

## Low-impact design

- The legacy Main-page Activity % column and its separate 2-second sampler daemon have been removed.
- Current open files are generated by the wake monitor from `/proc/*/fd` into `/var/local/emhttp/disk_open_files.json` (RAM).
- Power state uses Unraid's cached `disks.ini` first; `smartctl -n standby` is only an Auto fallback.
- Ordinary access events are kept in RAM. Only confirmed wake events are persisted to `/boot/config/plugins/disk.activity/wake-history.jsonl`.
- Wake history is automatically pruned by configured age and maximum-event limits.
